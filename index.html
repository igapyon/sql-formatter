DML/DQL（SELECT, INSERT, UPDATE, DELETE）と DDL（CREATE TABLE, ALTER TABLE など）のフォーマットに対応しています。

左で SQL を入力し、右で AST またはフォーマット結果を確認します。`Ctrl+Enter` / `Cmd+Enter` で Parse を実行できます。

SQL Input

入力欄は `lht-text-field-help` を使って統一し、ヘルプはコンポーネント側へ集約します。

Formatted Output

出力欄とコピー導線は `lht-preview-output` に寄せています。
